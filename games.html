WoW Client Setup

3.3.5a

Four steps: get the client, point it at the server, add the patch, then log in.

1

Download the WoW client

The server runs on client version 3.3.5a. If you don't already have a WoW folder on your computer, grab a clean client from ChromieCraft below. It's a big download (about 16.5 GB), so a torrent client (like qBittorrent) will usually be faster and more reliable than the direct download link.

Get the client →

Already have a 3.3.5a WoW folder from another server? You can reuse it. Just make sure the version matches 3.3.5a before moving on.

2

Point your client at the server

Inside your WoW folder, open Data \ enUS (or your language folder if you're not using English) and find a file called realmlist.wtf. Open it with Notepad, delete everything inside, and replace it with this single line:

realmlist.wtf
set realmlist game.gspeager.com

Save the file and close it. If Notepad won't let you save, right click the WoW folder, choose Properties, and make sure it's not set to Read Only.

3

Install the required patch

The server needs one small patch file on your end to work correctly.

Download link
https://github.com/heyitsbench/mod-arac/blob/master/Patch-A.MPQ
Get the patch →

Once downloaded, drop the patch file straight into the Data folder inside your WoW installation, right next to the other patch files already there. No need to unzip it into subfolders.

Close WoW completely before adding the patch, and make sure it's fully copied in before you launch the game again.

4

Log in and create your character

Run Wow.exe directly (not the Launcher) from your WoW folder. Enter the account username and password I gave you, pick the realm from the list, and create your character.

Don't have an account yet? Just message me and I'll set one up for you.

Palworld Setup

PC + XBOX + PS5

GBombPals

Works from Steam, the Xbox/Game Pass app, or PS5.

Server Address
game.gspeager.com
Port
8211
  1. Open Palworld and choose Join Multiplayer Game.
  2. Look for GBombPals in the community server list, or choose "Join by IP" and enter game.gspeager.com and the port above.
  3. Message me for the server password and enter it when prompted.
  4. Drop in, grab a Pal, and get building.

Password isn't posted here, just ask and I'll send it over.
